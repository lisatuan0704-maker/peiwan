TT 揪團角色圖片與 Discord 流程（2026-10-26）

網站端：
  const png = await TinyTavernUI.exportCharacterPng();
  // 或 TTCharacterSnapshot.exportCurrent({scale: 4})
  // 回傳 image/png Blob，預設 256 x 256；可選 1–8 倍整數像素縮放。

輸出重用既有 drawDollTo：64 x 64、idle、睜眼、透明背景。
保留角色裝扮及染色，不包含場景、座椅、名字、帳號資訊或獨立跟隨寵物。
只等待本次繪圖實際使用的圖片；逾時、缺圖、空白或無法讀取的跨來源圖片會失敗。
等待期間若帳號或穿搭改變，必須重新預覽。
此函式不會自行下載、上傳、修改角色或發送訊息；網站目前沒有公開揪團按鈕。

已部署的 TT 整合：
- Discord 固定入口先顯示當次須知，再由私人選單選遊戲、缺額、模式與氣氛。
- 最後可選填一句話；預設即時揪團，沒有約定時間欄位。
- 私人預覽會說明分享角色與網站暱稱將連結網站與 Discord 身分。
  使用者可選擇附上角色或不附角色；未同意時不公開網站角色及網站暱稱。
- 後端從已驗證的 Discord 互動身分取得自己的角色資料，使用隔離的網站繪圖器產生 PNG。
  不接受客戶端指定其他人的角色。前端輸出的圖片也不是身分或時裝所有權證明。
- 發布後是當次的造型快照；更換裝扮不會改動舊卡。
- 揪團卡貼至獨立佈告欄，附有簡短須知及「加入揪團／進入語音／退出揪團」。
- 每次加入都須確認須知；語音房最多五人，所有人可看見，只有確認並加入者獲得進房權限。
- 揪團者從「我的揪團」管理停止招募、重新招募、同行朋友與結束揪團。
  同行朋友各自確認須知後才能入座，不占對外招募缺額。
- 結束後刪除公開卡片；有人使用的語音房保留到空房再清理。
  開房十分鐘未入座，或使用後空房五分鐘，會自動結束；連線狀態不明時不刪房。

部署邊界：
TT 後端、憑證及伺服器設定不存放在本公開網站專案。
既有訂單語音通知仍由 lobby-ui/order-voice.mjs 呼叫 api.tinytavern.tw。
角色繪圖器使用固定版本的網站素材；新增服裝素材或改動繪圖邏輯後，需同步更新後端繪圖器。
維護時應先驗證實際角色預覽、Discord 發布及清理，再宣告新版本完成。
不得將 Discord Token、資料庫憑證或內部部署檔加入公開專案。

網站角色匯出測試：
  node tests/character-snapshot.cjs
需安裝 Playwright、pngjs 與 Chrome；TT_TEST_NODE_MODULES 可指定既有套件目錄。
測試以隔離角色資料執行，封鎖外部資料寫入與 WebSocket。
TT_SNAPSHOT_OUTPUT 可選填輸出測試 PNG 的資料夾。
